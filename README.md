# Dadum

맥에서 글을 고르면 옆에 [맞춤법 | 번역] 버튼이 뜨는 메뉴 막대 앱. 누른 쪽 하나만 돈다. 맞춤법은 Claude Haiku 5.5(`claude-haiku-5-5`, 빠름), 번역은 Claude Opus 5.5(`claude-opus-5-5`)가 한다.

## 설치

```
brew install --cask 0w0-dot/tap/dadum
```

macOS 14 이상. Apple Silicon 맥과 인텔 맥 모두 된다. 화면은 한국어.

Claude API 키가 있어야 한다. 키는 쓰는 사람마다 자기 것을 넣고, 비용도 그 키의 계정으로 나간다.

## 처음 한 번

- "손쉬운 사용" 권한을 켠다(시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 → Dadum). 다른 앱에서 고른 글을 읽고, 고친 글을 그 자리에 넣는 데 필요하다.
- 처음 버튼을 누르면 API 키 칸이 열린다. platform.claude.com에서 만든 키를 넣으면 하려던 검사가 바로 이어진다. 키는 키체인에만 둔다.

## 쓰는 법

- 글을 드래그하거나, 두 번 · 세 번 클릭하거나, ⌘A로 전체 선택하면 버튼이 뜬다.
- 맞춤법: 원래 글이 어떻게 바뀌는지 보여 준다(지운 말은 흐리게 긋고, 고친 말은 파란 굵은 글씨). 문장부호와 말끝은 원래대로 둔다.
- 번역: 마우스를 올리면 언어 메뉴가 열리고, 언어에 올리면 말투(일상 · 업무 · 정석)가 나온다. 한국어 글이면 영어 · 일본어 · 중국어, 다른 언어 글이면 한국어가 맨 위에 온다. 결과 창 제목은 "영어 · 업무"처럼 고른 것을 보여 준다.
- 한국어 글에서 메뉴 맨 아래 "한국어"를 고르면 번역이 아니라 그 말투로 다시 써 준다(예: 한국어 · 업무).
- 일본어 · 중국어 번역은 아래에 한국어로 되옮긴 뜻이 흐리게 붙는다.
- [번역]을 누르기만 하면 마지막에 고른 언어 · 말투로 바로 번역한다. 메뉴의 체크 표시가 그 선택이다.
- 바꾸기: 고친 글이나 번역을 고른 자리에 넣는다. 입력칸이 아니면 보이지 않는다.
- 복사: 클립보드에 담는다.
- Esc나 다른 곳 클릭으로 닫는다.
- 메뉴 막대 메뉴 맨 위에 이번 달 쓴 비용이 보인다(토큰 수로 셈한 어림값, 1달러 1,334원). 글 내용은 남기지 않고 숫자만 이 맥에 남긴다.

## 앱마다 글을 읽는 방법

- 맥 기본 앱(메모, 메일, 카카오톡 입력칸 등): 손쉬운 사용 정보로 읽는다. 클립보드를 건드리지 않는다.
- 크롬 계열(Chrome, Aside, ego lite)과 일렉트론 앱(Slack, Discord, Claude): 고른 글을 알려 주지 않아서 ⌘C로 복사해 읽고, 원래 클립보드를 바로 돌려놓는다.
- 구글 시트, Figma, Miro, Canva 페이지에서는 드래그가 칸 · 도형 고르기라서 복사하지 않는다(`SelectionReader.swift`의 `canvasPageTitles`).

## 빌드

```
./build.sh            # 빌드해서 /Applications 에 설치하고 실행
./build.sh --package  # 배포용 zip
```

개인 서명 인증서(`0w0-dot Code Signing`)로 서명해서, 새로 깔아도 권한과 키체인 접근이 유지된다.

## 새 버전 내기

`Resources/Info.plist`의 버전을 올리고 커밋한 뒤 `./release.sh`. 공개해선 안 되는 글(API 키 모양 글자 등)이 있으면 멈추고, 없으면 GitHub 릴리스를 올리고 Homebrew 설치 정보(`../홈브류-탭/Casks/dadum.rb`)의 버전과 확인값을 고친다.

## 점검

```
/Applications/Dadum.app/Contents/MacOS/Dadum --check "오늘 할수있을것 같아요" [모델]      # 맞춤법
/Applications/Dadum.app/Contents/MacOS/Dadum --translate "오늘 할수있을것 같아요" [영어|일본어|중국어|한국어] [일상|업무|정석] [모델]  # 번역
```

키체인의 키로 한 번 불러서 결과, 걸린 시간, 토큰 수를 찍는다. 모델을 적으면 그 모델로 해 본다.

기록: `/usr/bin/log show --last 10m --info --predicate 'subsystem == "io.github.0w0-dot.dadum"'` (앱 이름과 글자 수만 남고 글 내용은 남지 않는다).
